# Errors

## `ClientError`

`Client#mutate`, `Client#query`, `useQuery`, and `useMutation` all fail the same way: with a `ClientError`, never a raw `fetch` or parsing exception. Its `reason` field tells you what went wrong:

| `reason`              | Meaning                                                         |
| --------------------- | --------------------------------------------------------------- |
| `"network"`           | the request couldn't reach the server.                          |
| `"timeout"`           | the request took longer than the client's configured `timeout`. |
| `"httpStatus"`        | the response status was outside the `200`-`299` range.          |
| `"malformedResponse"` | the response body wasn't valid GraphQL JSON.                    |
| `"graphql"`           | the response came back with a top-level `errors` array.         |

### Usage

```ts
import { ClientError } from "@zoontek/gql-client";

try {
  await client.mutate(mutation, variables);
} catch (error) {
  if (error instanceof ClientError && error.reason === "graphql") {
    console.log(error.graphQLErrors);
  }
}
```

### Shape

```ts
class ClientError extends Error {
  reason: ClientErrorReason;
  url: string;
  response: Response | undefined;
  graphQLErrors: GraphQLError[];
}

type ClientErrorReason =
  "graphql" | "httpStatus" | "malformedResponse" | "network" | "timeout";
```

### Properties

| Property        | Type                    | Description                                                             |
| --------------- | ----------------------- | ----------------------------------------------------------------------- |
| `reason`        | `ClientErrorReason`     | Why the request failed, as listed above.                                |
| `url`           | `string`                | The request URL.                                                        |
| `response`      | `Response \| undefined` | The raw `fetch` response, when one was received.                        |
| `graphQLErrors` | `GraphQLError[]`        | The parsed `errors` array. Only populated when `reason` is `"graphql"`. |

`graphQLErrors` holds instances of `GraphQLError` from [`@0no-co/graphql.web`](https://github.com/0no-co/graphql-web), a dependency of this package. Import the type from there if you need to annotate it yourself.
