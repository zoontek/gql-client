# Authentication [Attach credentials to every request.]

The client's `transformRequest` returns the request to send instead of the one it built. Use it to add an auth header or send cookies.

## Static headers

For a token known at startup:

```ts title="src/client.ts"
import { Client } from "@zoontek/gql-client";
import schemaConfig from "./schemaConfig.json";

export const client = new Client({
  url: "https://api.example.com/graphql",
  schemaConfig,
  transformRequest: (request) => {
    request.headers.set("Authorization", `Bearer ${TOKEN}`);
    return request;
  },
});
```

## Per-request headers

The function runs for every request, so it can read the latest token. It can be async:

```ts title="src/client.ts"
export const client = new Client({
  url: "https://api.example.com/graphql",
  schemaConfig,
  transformRequest: async (request) => {
    const token = await getAccessToken();
    request.headers.set("Authorization", `Bearer ${token}`);
    return request;
  },
});
```

If the function throws or rejects, the request fails with a [`ClientError`](/errors) whose `reason` is `"transform"`.

## Cookies

To send cookies to a different origin, return a request with `credentials` set:

```ts title="src/client.ts"
export const client = new Client({
  url: "https://api.example.com/graphql",
  schemaConfig,
  transformRequest: (request) =>
    new Request(request, { credentials: "include" }),
});
```

## Signing the request body

Read the body from `request.clone()` to get the exact bytes the client will send, then pass the signature as a header:

```ts title="src/client.ts"
const encoder = new TextEncoder();

const key = await crypto.subtle.importKey(
  "raw",
  encoder.encode(SIGNING_SECRET),
  { name: "HMAC", hash: "SHA-256" },
  false,
  ["sign"],
);

export const client = new Client({
  url: "https://api.example.com/graphql",
  schemaConfig,
  transformRequest: async (request) => {
    const body = await request.clone().text();

    const signature = await crypto.subtle.sign(
      "HMAC",
      key,
      encoder.encode(body),
    );

    request.headers.set(
      "X-Signature",
      [...new Uint8Array(signature)]
        .map((byte) => byte.toString(16).padStart(2, "0"))
        .join(""),
    );

    return request;
  },
});
```

:::warning[Always clone before reading the body]
Reading `request.text()` directly consumes the body, and a request whose body has been consumed can no longer be sent. Such a request fails with a [`ClientError`](/errors) whose `reason` is `"transform"`.
:::

## On logout

Call `client.purge()` to drop every cached response, so the next user doesn't see the previous user's data. Mounted queries fetch fresh data.
