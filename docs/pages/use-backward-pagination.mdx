# useBackwardPagination

## `useBackwardPagination(connection)`

Takes the connection from a query result and returns it merged with every earlier page fetched for it with a `before` cursor, prepending each new page ahead of `connection`'s existing edges. Returns the connection unchanged until a previous page shows up in the cache.

```tsx
import { useQuery, useBackwardPagination } from "@zoontek/gql-client";
import { graphql } from "./gql";

const FilmReviewsQuery = graphql(`
  query FilmReviews($filmId: ID!, $last: Int!, $before: String) {
    film(id: $filmId) {
      id
      reviewsConnection(last: $last, before: $before) {
        edges {
          node {
            id
            comment
          }
        }
        pageInfo {
          hasPreviousPage
          startCursor
        }
      }
    }
  }
`);

const FilmReviews = ({ filmId }: { filmId: string }) => {
  const [{ data, fetching }, { setVariables }] = useQuery(FilmReviewsQuery, {
    filmId,
    last: 3,
  });

  const connection = useBackwardPagination(data.film?.reviewsConnection);

  return (
    <>
      {connection?.pageInfo.hasPreviousPage ? (
        <button
          disabled={fetching}
          onClick={() =>
            setVariables({ filmId, before: connection.pageInfo.startCursor })
          }
        >
          Load earlier reviews
        </button>
      ) : null}

      <ul>
        {connection?.edges?.map((edge) =>
          edge?.node == null ? null : <li key={edge.node.id}>{edge.node.comment}</li>,
        )}
      </ul>
    </>
  );
};
```

`setVariables({ before })` alone would only make `data.film.reviewsConnection` hold the new page. `useBackwardPagination` is what keeps the later edges around and prepends the new ones as they arrive.
