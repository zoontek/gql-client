# useMutation [Send a mutation and update paginated connections it affects.]

Returns a `mutate` function for `mutation` against the `Client` from the nearest `ClientProvider`, and its current state.

## Basic usage

```tsx title="src/FilmRatingForm.tsx"
import { useState } from "react";
import { useMutation } from "@zoontek/gql-client";
import { graphql } from "./gql";

const RateFilmMutation = graphql(`
  mutation RateFilm($filmId: ID!, $stars: Int!) {
    rateFilm(filmId: $filmId, stars: $stars) {
      film {
        id
        averageRating
      }
    }
  }
`);

const FilmRatingForm = ({ filmId }: { filmId: string }) => {
  const [state, rateFilm] = useMutation(RateFilmMutation);
  const [stars, setStars] = useState(5);

  const onSubmit = (event: React.FormEvent) => {
    event.preventDefault();
    rateFilm({ filmId, stars });
  };

  return (
    <form onSubmit={onSubmit}>
      <input
        type="number"
        min={1}
        max={5}
        value={stars}
        disabled={state.fetching}
        onChange={(event) => setStars(Number(event.target.value))}
      />
      <button type="submit" disabled={state.fetching}>
        Submit rating
      </button>
    </form>
  );
};
```

## Signature

```ts
type MutationState<Data> =
  | { fetching: false; status: "idle" }
  | { fetching: true; status: "loading" }
  | { fetching: false; status: "success"; data: Data }
  | { fetching: false; status: "error"; error: ClientError };

type Mutation<Data, Variables> = readonly [
  MutationState<Data>,
  (variables: Variables) => Promise<Data>,
];

type MutationConfig<Data, Variables> = {
  connectionUpdates?: GetConnectionUpdate<Data, Variables>[];
};

function useMutation<Data, Variables>(
  mutation: TypedDocumentNode<Data, Variables>,
  config?: MutationConfig<Data, Variables>,
): Mutation<Data, Variables>;
```

## Params

| Param                      | Type                                     | Description                                                  |
| -------------------------- | ---------------------------------------- | ------------------------------------------------------------ |
| `mutation`                 | `TypedDocumentNode<Data, Variables>`     | Your mutation document node.                                 |
| `config.connectionUpdates` | `GetConnectionUpdate<Data, Variables>[]` | Optional. See [Updating connections](#updating-connections). |

## Returns

A `[state, mutate]` tuple:

| Field               | Type                                      | Description                                                                                                                                                                                                          |
| ------------------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `mutate(variables)` | `(variables: Variables) => Promise<Data>` | Sends the mutation, and updates `state` as it settles. Returns a promise resolving with the response data. If called again before the previous call resolves, only the latest call's result is reflected in `state`. |
| `state`             | `MutationState<Data>`                     | Narrowed on `status`, see the table below.                                                                                                                                                                           |

| Status      | Shape                                          |
| ----------- | ---------------------------------------------- |
| `"idle"`    | `{ status: "idle", fetching: false }`          |
| `"loading"` | `{ status: "loading", fetching: true }`        |
| `"success"` | `{ status: "success", fetching: false, data }` |
| `"error"`   | `{ status: "error", fetching: false, error }`  |

## Updating connections

A mutation only writes the fields it selects; it doesn't know which cached [connections](/pagination) should gain or lose an edge as a result. `connectionUpdates` fills that gap. Say a film has a paginated `reviewsConnection`, and `film` here is the value read from an earlier `useQuery`:

### Usage

```ts
const CreateReviewMutation = graphql(`
  mutation CreateReview($filmId: ID!, $comment: String!) {
    createReview(filmId: $filmId, comment: $comment) {
      review {
        id
        comment
      }
    }
  }
`);

useMutation(CreateReviewMutation, {
  connectionUpdates: [
    ({ data, append }) =>
      data.createReview?.review == null
        ? undefined
        : append(film.reviewsConnection, [
            { __typename: "ReviewEdge", node: data.createReview.review },
          ]),
  ],
});

const DeleteReviewMutation = graphql(`
  mutation DeleteReview($reviewId: ID!) {
    deleteReview(reviewId: $reviewId) {
      deletedReviewId
    }
  }
`);

useMutation(DeleteReviewMutation, {
  connectionUpdates: [
    ({ data, variables, remove }) =>
      data.deleteReview == null
        ? undefined
        : remove(film.reviewsConnection, [variables.reviewId]),
  ],
});
```

Each entry in `connectionUpdates` is called with the mutation's `data` and `variables`, plus three helpers, and returns their result to describe the change, or `undefined` to leave the connection as-is:

### Signature

```ts
type GetConnectionUpdate<Data, Variables> = (config: {
  data: Data;
  variables: Variables;
  prepend: <A>(
    connection: Connection<A>,
    edges: Edge<A>[],
  ) => ConnectionUpdate<A>;
  append: <A>(
    connection: Connection<A>,
    edges: Edge<A>[],
  ) => ConnectionUpdate<A>;
  remove: <A>(connection: Connection<A>, ids: string[]) => ConnectionUpdate<A>;
}) => ConnectionUpdate<unknown> | undefined;
```

| Helper                       | Type                                                                   | Description                                           |
| ---------------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------- |
| `prepend(connection, edges)` | `(connection: Connection<A>, edges: Edge<A>[]) => ConnectionUpdate<A>` | Adds `edges` before `connection`'s existing ones.     |
| `append(connection, edges)`  | `(connection: Connection<A>, edges: Edge<A>[]) => ConnectionUpdate<A>` | Adds `edges` after `connection`'s existing ones.      |
| `remove(connection, ids)`    | `(connection: Connection<A>, ids: string[]) => ConnectionUpdate<A>`    | Drops the edges whose node `id` matches one in `ids`. |
